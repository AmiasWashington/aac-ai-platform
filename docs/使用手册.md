# AAC 活动本位辅助沟通平台 · 使用手册（v0.3）

版本：研究原型 v0.3 ｜ 适用对象：特教教师、康复治疗师、家长

---

## 0. 如何打开

### 最简单：单文件版（推荐）

双击 `AAC沟通平台-单文件版.html`，用系统浏览器（Windows 用 Edge/Chrome）打开即可。
该文件已把样式、脚本、图卡图形全部打包，**不需要联网、不需要 VPN、不需要本地服务器**，也可以直接转发给别人。

> ⚠️ 不要在微信/QQ 的"文件预览"里打开——内置预览会禁用网页脚本，页面会显示空白。
> 若默认被微信打开：右键文件 → 打开方式 → Microsoft Edge。

打开后默认进入口页，选择"学生使用"或"教师管理"；右下角悬浮条可在【入口 / 学生端 / 教师端】之间切换。
学生端为保持纯净隐藏了悬浮条，点右上角「设置」输入教师密码（默认 0000）即可进入教师端。

### 其他打开方式

- 分文件版（便于二次开发）：在本文件夹执行 `python -m http.server 8777 --directory .`，
  浏览器访问 `http://127.0.0.1:8777/index.html`。
  若直接双击 `index.html`，**必须保证 `assets/` 文件夹与三个 html 同目录**，否则页面空白。
- **投屏/平板**：打开学生端后点底部"全屏"，再把设备交给学生。

> 数据保存在本机浏览器，不上传。学生端与教师端是两个页面，共用同一份数据。

## 1. 两套界面，各司其职

**学生端（student.html）** 只有沟通板本身：上方消息条、一行常驻核心词、主题页图卡区、底部导航。
没有统计、没有报告、没有任何设置项——这样学生不会被无关信息分散注意，也不会误触改动配置。

**教师端（teacher.html）** 负责全部管理与分析：图卡库、活动与介入路径、使用统计、观察报告、
沟通板设置、数据备份。学生端右上角的"设置"需要教师密码（默认 **0000**）才能进入。

## 2. 五分钟上手（学生端）

1. **点图卡**：图卡进入上方消息条，同时读出名称（可在教师端关闭朗读）。
2. **说一句**：按顺序连读消息条上的全部图卡。
3. **删一个 / 清空**：删掉最后一张，或把消息条清空；点消息条里的某张图卡可以只删那一张。
4. **换主题页**：底部切换"吃饭 / 生活自理 / 上课 / 身体情绪 / 玩耍 / 人 / 礼貌用语"，
   或点"活动"进入某个具体活动的图卡。
5. **锁定与全屏**：把设备交给学生前点"锁定"防误触；长按任意位置 2 秒或连续点 5 下解锁。

### 关于"常驻核心词"

学生端最上方那一行（我要、不要、帮我、更多、完成、停、等一等、看）是**位置固定、不随主题页变化**的核心词。
这样学生可以靠位置记忆快速找到最常用的表达，对应"核心词尽早稳定、少变动"的设计原则。

## 3. 教师端：图卡库

每张图卡维护四件事：

- **名称与拼音**：拼音可在学生端显示，帮助识字过渡期的儿童。
- **词性**：决定卡片颜色，见下表。
- **所属主题页**：决定它出现在学生端哪一页。
- **是否常驻核心词**：勾选后固定出现在学生端最上方一行。

| 词性 | 颜色 | 例 |
| --- | --- | --- |
| 人称词 | 黄 | 我、老师、同学 |
| 动作词 | 绿 | 吃、洗手、看 |
| 事物词 | 橙 | 米饭、球、玩具 |
| 描述词 | 蓝 | 高兴、疼、更多 |
| 社交词 | 粉 | 老师好、谢谢 |
| 否定词 | 红 | 不要、停 |
| 结构词 | 紫 | 我要 |

**图片**：内置的是矢量图形；点"选择图片"可上传真实照片，系统自动压缩到 320 像素并给出分辨率、
构图比例自检，随时可"恢复内置图形"。

**真人语音**：点"开始录音"用手机/平板麦克风录一段（例如家长或老师读"喝水"），
系统会优先播放录音而非合成语音——熟悉的声音通常更容易被儿童接受。

## 4. 教师端：活动与介入路径

给每个活动打两个分数：

| 评分 | 含义 | 参考取值 |
| --- | --- | --- |
| 沟通机会密度（1–5） | 活动里自然产生多少次"需要沟通"的时刻 | 如厕 1–2；午饭、课间游戏 4–5 |
| 可预测性（0–100） | 这些时刻是否每次都差不多、位置固定 | 如厕、洗手 80–95；自由游戏 20–40 |

- **可预测性 ≥ 60** → **活动序列**：按固定流程把图卡排好序，学生端"活动"页里图卡带序号固定排列。
- **可预测性 < 60** → **情境推荐**：按当前情境调整图卡的先后与凸显，并给出沟通伙伴提示
  （等待时长、提示语、应避免的行为）。情境由教师在教师端设置。

活动里的**沟通节点**（例如如厕：表达需求 → 请求协助 → 不适/拒绝 → 完成标记 → 洗手衔接）
会在教师端与学生端的活动提示中显示，提醒在这些时刻留意等待与提示方式。

## 5. 教师端：使用统计与观察报告

**使用统计**：使用次数、覆盖活动数、跨活动复用率（覆盖活动数 ÷ 活动总数）。
当复用率 ≥ 0.60 且覆盖 ≥ 3 个活动时，系统提示"建议设为常驻"，并提供三个人工入口：

- **采纳**：把这张图卡设为常驻核心词；
- **锁定**：认为它重要，后续不再被自动建议改动；
- **忽略**：不采纳，且不再重复提示。

**观察报告**：响应延迟分布、沟通失败模式（无回应、指向错误图卡、有提示后完成）与重复无效点击合计，
并自动生成一段**观察摘要**。摘要只写可观察的事实，例如"在'午饭'活动中，'帮我'的 7 次点击里有 3 次无后续回应"，
**不会**写"孩子没有掌握'帮我'"这类归因判断。摘要可导出，用于教研讨论与家校沟通。

## 6. 教师端：沟通板设置与数据

- **网格列数/行数**：列数决定一行放几张卡；行数是上限，实际行数按图卡数量自适应，卡片会随之放大。
  建议平板横屏用 5–6 列。
- **拼音 / 常驻核心词行 / 点图卡即朗读 / 语速**：随时可改，学生端刷新即生效。
- **教师端进入密码**：默认 0000，建议改成学生猜不到的号码。
- **数据**：导出/导入 JSON 备份、恢复演示数据、清空数据。

**隐私**：数据只保存在本机浏览器，不上传；使用者名称建议使用化名。
导出文件包含儿童沟通过程数据（活动、图卡、表达结果、响应延迟），请妥善保管，
不要随意外发。相关要求可参照《中华人民共和国个人信息保护法》与《儿童个人信息网络保护规定》。

## 7. 常见问题

**Q：学生端没有声音？**
A：检查"沟通板设置"里的语音开关与语速；设备需要安装中文语音（Edge/Chrome 一般自带）。
关键图卡也可以录一段真人语音。

**Q：学生端卡片太小 / 太大？**
A：把列数调小（例如 4 列）卡片会变大；行数是上限，实际行数会按该页图卡数量自适应。

**Q：学生误入设置界面怎么办？**
A：学生端设置需要密码；日常把学生端"锁定"或全屏后交给学生即可。

**Q：能多人使用吗？**
A：当前是单机原型，用"使用者称呼"区分记录对象；多人协作属于后续版本范围。

**Q：为什么有些提示写着"未接入模型"？**
A：图像质量评分与标签建议是按规则计算的演示内容；图卡、活动、日志、统计与报告都是真实功能。
