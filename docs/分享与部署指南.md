# 分享与部署指南

> 面向两种需求：① 把平台分享给其他老师使用；② 把原型发布到 GitHub 供同行查看与复现。

---

## 一、先看结论：三种分享方式怎么选

| 方式 | 适合场景 | 对方需要做什么 | 数据 | 国内可用性 |
| --- | --- | --- | --- | --- |
| **① 单文件 HTML**（发文件） | 给一线教师、家长日常使用；微信/邮件/U盘转发 | 下载后双击，用 Edge/Chrome 打开 | 各自电脑本地保存 | ★★★★★ 完全离线，不受任何限制 |
| **② 一个网址**（部署到静态托管） | 同行试用、评审查看、教研活动统一入口 | 点开链接即用 | 各自浏览器本地保存 | ★★★☆☆ GitHub Pages 可能慢/打不开；Gitee、国内对象存储更快 |
| **③ 文件夹或打包成应用** | 有人要改代码、二次开发 | 需要开发环境 | — | 视部署方式而定 |

**建议：两者都提供。** 在线网址给同行看，单文件版给真正要用的老师——后者在他们电脑上永远不会因为网络问题打不开。

---

## 二、方式①：单文件 HTML（最省事，推荐给一线教师）

- 文件：`dist/AAC沟通平台-单文件版.html`（约 130 KB），随文件附一份 `dist/AAC沟通平台-使用说明.txt`
- **发送方式**：微信、QQ、邮件、U 盘都行，发一个文件即可，不会出现"少文件打不开"
- **对方怎么用**：下载 → 双击 → 用 **Edge / Chrome** 打开
- ⚠️ **不要用微信/QQ 的"文件预览"打开**：内置预览会禁用网页脚本，会显示空白。若默认被微信接管，右键 → 打开方式 → Microsoft Edge
- 小技巧：手机/平板上用浏览器打开后选择"添加到主屏幕"，就会像 App 一样有图标

优点：零依赖、零网络请求、不受访问限制；缺点：数据在各自设备上，不互通（见第五节）。

---

## 三、方式②：做成一个网址

### 3.1 GitHub Pages（免费，本仓库已具备条件）

网页操作（最简单）：

1. 登录 GitHub → **New repository**，仓库名如 `aac-ai-platform`，可见性选 **Public**
2. 进入仓库 → **Add file → Upload files**，把本项目里的 `index.html`、`student.html`、`teacher.html` 与 `assets`、`screens`、`docs`、`dist` 文件夹一起拖进去 → **Commit changes**
3. **Settings → Pages**：Source 选 `Deploy from a branch`，Branch 选 `main`、目录选 `/(root)` → **Save**
4. 等 1–2 分钟，访问 `https://<你的用户名>.github.io/<仓库名>/`

命令行方式（可选）：

```bash
git init
git add .
git commit -m "init: AAC 活动本位辅助沟通平台 v0.3"
git branch -M main
git remote add origin https://github.com/<用户名>/<仓库名>.git
git push -u origin main
```

> 仓库根目录已经有 `index.html`（入口页），正是 GitHub Pages 需要的首页，**不需要改任何代码**。
>
> ⚠️ **GitHub Pages 在国内访问可能很慢或打不开**——这不是代码问题。如果要面向国内老师，建议同时提供方式①，或用下面的 3.2–3.4。

### 3.2 Gitee Pages（码云，国内更快）

新建仓库 → 上传同样文件 → 服务 → Gitee Pages → 部署。
需要实名认证；Pages 是否开通及具体规则以平台当前政策为准。

### 3.3 Vercel / Netlify / Cloudflare Pages

用 GitHub 账号登录 → Import 这个仓库 → 直接部署（纯静态站点，不需要构建命令）→ 得到 `xxx.vercel.app` 之类的网址。
国内一般可以访问，偶尔较慢；适合给同行看，不太适合作为长期教学入口。

### 3.4 国内对象存储 / 静态网站托管（最稳，正式给老师用推荐这个）

腾讯云 COS、阿里云 OSS、七牛云等：把 `index.html`、`student.html`、`teacher.html` 与 `assets/` 上传为**静态网站**，绑定自己的域名（国内域名需备案）。
优点：国内访问快、可配 HTTPS；缺点：需要实名与少量费用。

### 3.5 单位服务器或内网临时共享

把文件夹放到学校服务器；或者教研活动当场演示：

```bash
python -m http.server 8777
# 同一 WiFi 下，其他老师用 http://<你的电脑IP>:8777/ 访问
```

### 3.6 生成二维码

把在线网址生成二维码（微信扫码可直接在浏览器打开），打印在讲义上或投屏，老师扫码即用。

## 四、方式③：打包成"应用"（一般不需要）

| 目标 | 做法 | 成本 | 建议 |
| --- | --- | --- | --- |
| 手机/平板桌面图标 | 改造成 PWA（加 manifest 与 service worker） | 半天左右 | 想要"像 App"又不想上架，优先选这个 |
| Windows 桌面程序 | Electron / Tauri 包壳成 exe | 体积大、需签名 | 除非要离线分发给完全不懂电脑的使用者 |
| 安卓 App | WebView 壳 + 打包 apk | 上架需资质 | 有明确上架需求时再说 |

**结论**：给老师用，"在线网址 + 单文件版"已经足够；真要更像应用，先做 PWA 就够（不需要应用商店）。

---

## 五、数据与协作：三种方式都要注意的一点

- 三种方式的数据都保存在**使用者自己的浏览器**里，**不会上传、也不会自动同步**。
- 因此：每位老师的数据互相独立；换电脑、换浏览器、清理浏览器数据都会丢 → 提醒他们定期在**教师端 → 数据与备份 → 导出备份**。
- 如果未来需要"多设备同步""多人协作""机构级统计"，就必须加后端（自建 API、Supabase、Firebase 等），这属于下一阶段开发，不在当前原型范围内。

## 六、发布到 GitHub：需要分享哪些材料

### 必需（没有就不算一个能跑的仓库）

| 文件/文件夹 | 作用 |
| --- | --- |
| `index.html`、`student.html`、`teacher.html` | 入口页 / 学生端 / 教师端 |
| `assets/`（`store.js`、`cards.js`、`student.js`、`teacher.js`、`app.css`、`symbol.css`、`student.css`） | 全部逻辑与样式，缺一个页面就白屏 |
| `README.md` | 项目说明、截图、运行方式、隐私与免责声明 |
| `LICENSE` | 授权方式（默认 MIT，可改） |
| `.gitignore` | 防止把备份数据、缓存、临时文件提交上去 |

### 推荐（体现研究属性、方便他人复现）

| 文件/文件夹 | 作用 |
| --- | --- |
| `dist/AAC沟通平台-单文件版.html` | 离线版，别人不用装环境就能试用 |
| `docs/使用手册.md` | 学生端 / 教师端逐步说明 |
| `docs/分享与部署指南.md` | 本文件 |
| `docs/图注与插入建议.md` | 论文插图与图注对应关系 |
| `docs/论文插图/`（12 张） | 论文第四章用图，便于他人对照设计逻辑 |
| `screens/`（10 张） | README 里的界面截图 |
| `CITATION.cff` | GitHub 会显示"Cite this repository"，方便他人引用 |
| `CHANGELOG.md` | 版本演进（v0.1 静态稿 → v0.2 单页应用 → v0.3 双端分离） |

### 不要上传

- 任何**含真实儿童数据**的备份 JSON（`aac-platform-backup.json`、导出的观察摘要等）
- 含真实姓名、学校班级、可识别儿童身份的照片（本仓库演示数据均为虚构示例）
- 编辑器/系统缓存（`.vscode/`、`__pycache__/`、`.DS_Store` 等，已在 `.gitignore` 中排除）

### 发布前自检清单

- [ ] 用 Edge/Chrome 双击 `dist` 里的单文件版，确认能打开
- [ ] 本地起服务后，`index.html → 学生端 → 教师端` 三条路径都走通
- [ ] 手机上也试一次（学生端建议横屏 + 全屏）
- [ ] 仓库里没有真实儿童数据
- [ ] 把 `README.md` 与 `CITATION.cff` 里的 `<你的用户名>/<仓库名>` 换成真实地址
- [ ] 决定许可证（默认 MIT；若要"署名 + 非商业"可换 CC BY-NC-SA 4.0）

### 建议的仓库设置

- **About**：写一句简介 + 勾选 Topics：`aac`、`special-education`、`assistive-technology`、`prototype`、`china`
- **Releases**：把 `dist/AAC沟通平台-单文件版.html` 作为附件发一个 `v0.3.0` Release，老师可直接下载，不必进代码目录
- **Issues**：开放 issue，收集一线教师的使用反馈（比微信群反馈更容易沉淀）
